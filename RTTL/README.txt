real-time-txt-lite (RTTL) - Windows 实时字幕翻译

版权、非商业使用限制和第三方权利声明见同目录 README.md。
未经著作权人事先书面许可，禁止将本项目及其修改版、衍生版用于商业用途。

当前仅支持 Windows 11 x64，不支持 Windows 10、macOS 或 Linux。
实时字幕只需在其“字幕语言”菜单中为所用识别语言下载语音包，无需完整 Windows 显示语言包，也不必为翻译目标安装语音包。
翻译需要单独的 Edge 本地翻译模型；缺少资源时需联网下载。
语言包和翻译模型不包含在本项目文件夹中，已安装的资源无需重复下载。

悬浮窗设置和网页提供官方示例的 154 个候选语言／变体，源语言与目标语言独立选择，默认英文翻译中文。
外面的中英快捷按钮保留英语（美国，en-US）与中文（简体，中国大陆，zh-CN）的同步识别切换。
英文、简体中文、日文置顶，其余保留官方示例顺序；候选数量不代表每个语言对均可用，实际由 Edge 本地 API 检查。
微软云端翻译的语言数量不等同于 Edge 本地模型能力；网页选择不会更改原生实时字幕的语言范围。
候选项也不代表 Windows 字幕能识别所有语言，其他源语言须在原版字幕中手动选择并下载语音包。

数据与隐私：内容数据纯本地处理，本项目不会上传。
字幕原文、译文、手动输入和会议记录在本机处理与保存，不由本项目上传至外部服务器，不使用云端翻译。
程序与 Edge 翻译页面仅通过 127.0.0.1 本机回环地址交换数据。
语言包和模型下载需要联网，但不等于上传会议内容；本声明不保证 Windows、Edge 或整台电脑完全不联网，也不涵盖用户自行同步或分享文件。
会议 TXT 为本地明文文件，仍需按组织保密要求管理。

一、启动
将整个 RTTL 文件夹解压或复制到本机，双击 RTTL.exe，也可继续使用 start.bat。
不要在 ZIP 内直接运行，不要只发送 EXE 或 start.bat，也不要移动内部文件或直接双击 DLL。
EXE 为未签名的 x64 .NET Framework 图形程序，不是单文件版；仍需保留 web 和 config。无需安装 Visual Studio、.NET SDK 或开发工具。
本次 EXE 仅完成编译与静态检查，没有运行；若被组织策略阻止，请联系 IT 审批，不要绕过防护。

二、电脑要求
Windows 11 x64、.NET Framework 4.8.1 Runtime、Microsoft Edge 148 或更新版本。EXE 启动不依赖 PowerShell，仅原 BAT 启动需要 Windows PowerShell 5.1。
首次运行需要完成 Windows 实时字幕授权并安装对应识别语言包。
Edge 页面每次打开先检查：缺少模型时提示“点击下载微软翻译模型”，下载期间显示“下载中...”。
双向模型已下载或下载完成后显示“已安装”，不会自动重复下载。
下载完成不自动做翻译测试；已安装时可点击同一按钮检查双向连通。
首次下载语言包或翻译模型可能需要联网。已下载模型由 Edge 管理，不包含在本文件夹内。
如组织策略阻止脚本、DLL、本机监听或 Translator API，请联系 IT 授权，不要关闭安全防护。

三、使用
默认直接英语翻译中文，无需勾选首次确认。Windows 实时字幕需设为英语，并能实际显示英文原文。
启动不自动检测或更改 Windows 识别语言。右上角方向按钮可同步切换识别语言和翻译方向。
仅使用 English (United States) 与中文（简体，中国大陆），识别语言包需先在 Windows 手动安装。
切换未确认成功时会提示，并保留原翻译方向；也可在原版字幕中手动检查设置。
右上角麦克风按钮切换 Windows 字幕的麦克风识别，不是系统静音；未连接原版字幕窗口时不可用。
旧版英语未确认的设置升级后会自动启用，不需要删除个人设置或会议记录。
悬浮窗设置中分别选择源语言和目标语言，选中立即应用并保存，不再需要应用按钮或确认勾选；选到另一端语言时自动交换。更换源语言须在 Windows 字幕中手动选择对应语言，程序不自动检测。
缺少所选字幕模型时，在 Edge 页面点击“下载所选字幕模型”，不因更改设置自动下载。中英快捷按钮可随时切回中英方向。
网页首次打开与悬浮窗方向相同，之后两端不联动，重连不覆盖网页选择；两端新增交换方向箭头，点击交换各自源／目标语言。悬浮窗交换立即应用并保存，源语言变化后仍须手动匹配 Windows 识别语言，无需确认勾选，外面的中英快捷按钮保留。
播放系统音频后，翻译板默认保留最近四条译文，可在设置中选 2–6 条，选中立即保存；已有个人选择不强制覆盖。每条另起一行，长段自动按窗口宽度折行，原文保留在 Windows 字幕窗。
设置窗口默认加宽至最多 900、高度增至 340，行数标签和选择框保持同一行。
中英文逗号均可分段，1,000 等数字中的逗号保留，不把数字拆开。
译文默认黑色，设置中的色块可切换黑、白、绿、蓝、红，立即生效并随个人设置保存。
翻译框采用紧凑布局，默认高度 124，底部状态字号为 9；旧默认高度自动迁移，其他自定义高度保留。
右下角手柄放大并按屏幕位移处理连续调整；设置中的“窗口高度”滑杆支持 96–1200，直接调节并保存，跟随时实际高度受屏幕可用空间限制。
字幕优先读取 UIA 可见文字范围，避免完整名称中的滚出旧句残留；不支持的控件保留原读取方式，实际兼容性仍需真机确认。
新句待译、识别修订或可见范围短暂为空时，保留最近译文；实时结果返回时，即使源句刚滚出画面，也可更新最近可用译文。较旧结果不覆盖较新译文，历史补译不重新补播。
可见范围从当前未完句中间开始时，匹配尾部仍允许显示该句译文；清空按钮、切换方向和会话重置仍清除显示。
长译文不再以省略号截断，超出窗口高度时可滚动查看当前内容，完整内容按记录规则写入 TXT。首次尚无译文时仍显示等待，模型不返回或设备性能问题需另行排查。
最多同时翻译两条，两个通用槽位共用队列，优先最新字幕，任务优先按 A、B、A、B 交替分派；轮到的槽忙时使用另一空闲槽，不固定分为实时或历史用途。
同一句段的两个版本不会同时执行，新版等旧调用结束；识别修订仍可后续重译，其他句段不受此等待影响。手动翻译计入两条总上限。
第二槽按需创建独立 Translator 会话，会话重置或退出时释放；实际推理性能由 Edge 和设备决定，不保证速度翻倍。
默认静默去抖 700 ms，同一片段的连续预览间隔 1500 ms；已有个人设置保留。失败或空译文最多重试两次，重试耗尽显示失败计数。
Edge 页面可选择源语言和目标语言进行多语言文本翻译，缺少所选模型时点击“下载模型并翻译”。
Windows 语音包自动检测已取消，不再显示“可用”或“未安装”；启动、重连和切换语言均不再自动查询。
“文本翻译”标题旁保留“字幕语音包安装说明”链接，请在 Windows 实时字幕中选择语言并下载语音包，不自动安装或切换语言。
Windows 语音包与 Edge 翻译模型分开，纯文本翻译不要求安装 Windows 语音包。
手动译文与完成的字幕会自动写入同一份会议 TXT。
手动译文收到实际写盘确认后才显示“已写入会议记录”。

四、会议记录
默认开启本地记录，文件可能包含会议原文、译文及手动输入文本，请遵守保密要求。
记录目录：%LOCALAPPDATA%\LCET\transcripts
可从悬浮窗设置中的“记录文件夹”打开，每次运行一个 UTF-8 TXT；后台每 4 秒合并追加一次，正常退出立即补写剩余记录。
强制结束或断电可能丢失尚未写入的内容，不能保证完整记录。
隐私模式已移除，旧配置中的对应字段会被忽略，不再限制记录或复制；已有文件不删除。
正常退出时选择是否保留本次记录；以前的记录不自动清理，请自行管理保留期和磁盘空间。
过载、磁盘故障或翻译失败可能缺句。
个人设置：%LOCALAPPDATA%\LCET\settings.json
技术日志：%LOCALAPPDATA%\LCET\logs\technical.log
本发布文件夹不包含打包电脑的个人设置、会议记录或浏览器模型。

五、退出与故障
通过悬浮窗右上角的退出按钮结束应用。
运行期间仍自动写 TXT，正常退出先结束写盘，再询问是否保留本次记录。
选择“是”：保留并用系统默认应用打开本次 TXT。
选择“否”：删除本次 TXT，不影响以前的记录。
没有本次记录时不弹提示；强制关闭进程无法保证弹出确认，已写出的文件可能保留。
保存、删除或打开失败时会提示本次文件路径，请按提示检查。
应用会停止任务并释放翻译会话；浏览器拒绝自动关闭时，手动关闭本项目标签即可。
不会结束其他 Edge 窗口或整个浏览器进程。
启动失败时查看控制台提示；若缺少运行环境请安装对应官方组件。
本版本仍需在目标办公电脑验证长时间会议、离线重启和企业策略兼容性。
程序只读取 Windows 字幕，不接管音频或修改识别结果；Edge 模型仍会占用系统资源，不能保证完全没有性能影响。
