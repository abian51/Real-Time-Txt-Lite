# real-time-txt-lite (RTTL)

Windows 11 本地字幕翻译 MVP：Windows 实时字幕 → UI Automation → 内存字幕处理 → 回环 SSE → 真实 Microsoft Edge Translator API → WPF 译文悬浮窗。

网页手动翻译和悬浮窗设置均提供独立源语言、目标语言，默认英文→中文，共用微软官方示例中的 154 个候选语言／变体，英文、简体中文、日文置顶，其余保留官方示例顺序。候选列表不是全部语言对或 Windows 识别可用的保证，翻译能力按 Edge 的 `Translator.availability()` 检查。悬浮窗选择后立即应用并保存，无需应用按钮或确认勾选；选到另一端语言则自动交换。更换源语言仍需在 Windows 实时字幕手动选择对应识别语言，不新增自动检测。外面的中英按钮保留美式英语／简体中文识别与双向翻译快捷切换。网页手动翻译方向与字幕方向独立。

## 使用

1. 将整个目录复制到电脑，双击 [start.bat](start.bat)。不需要管理员、.NET SDK 或 Visual Studio。
2. 首次运行完成 Windows 实时字幕的授权与识别语言包安装。Edge 页面每次打开先检查模型：缺少时提示“点击下载微软翻译模型”，点击后显示“下载中...”，双向模型已下载或下载完成后显示“已安装”。模型下载需要用户点击，不自动接受微软授权。下载完成不自动做翻译测试；已安装时可点击同一按钮检查双向连通。
3. 默认直接英语→中文，不需要首次手动确认。首次请将 Windows 实时字幕的识别语言设为 English (United States)；启动时不自动检测或更改它。之后可点击右上角的方向按钮，同步切换 Windows 识别语言与翻译方向，仅使用美式英语和中文（简体，中国大陆）。需先手动安装对应识别资源，操作未确认成功时会提示，不提前改变翻译方向。
4. 播放系统音频即可接收字幕。右上角麦克风按钮可切换 Windows 实时字幕的麦克风识别；未绑定原版字幕窗口时不可用。
5. 在 LCET 窗口点击“退出”完整停止。有本次记录时会询问是否保留：选择“是”保留并打开 TXT，选择“否”删除本次 TXT，不影响以前的记录。原有 Windows 字幕和无关 Edge 页面不会被结束。

主窗口无边框、无标题栏，始终置顶，最多显示 Windows 当前字幕快照中最近三段的译文，每段另起一行，长段按窗口宽度自动折行，不显示原文或历史列表。中英文逗号 `，`、`,` 参与分段，数字中的逗号（如 `1,000`）保留。先确定当前段的显示资格，再判断译文是否返回，不用历史结果补满三段。更新复用同一个文字控件，显示缓存最多三条，不随会议时长增加界面节点。默认开启设置中的“跟随 Windows 字幕”：自动贴在原版字幕下方，空间不足时放在上方，位置与宽度同步变化；握柄只调高度。关闭跟随后恢复原来的独立位置和尺寸，可拖动空白/字幕区域移动、右下角握柄调整宽高，最小尺寸 420×160。默认高度 160，比原来的 240 减少三分之一；旧默认高度自动迁移，其他自定义高度保留。

背景默认不透明度 50%，可在设置中调整到 0–100%；原文、译文与按钮保持完全不透明。底部三个状态合并在同一行，较长状态内容省略，悬停查看完整信息；右上角包含麦克风、翻译方向、设置和退出按钮。

新句等待译文、识别修订时，只保留仍属于当前显示范围的已有译文；Windows 已滚走或替换的旧句立即退出显示，之后迟到的结果只按记录规则写入 TXT，不滚动补播。Windows 清空字幕时也清空译文区。持续讲话时约每 800 ms 允许提交一次当前片段，避免一直等待停顿。长译文自动换行，不再以行末省略号截断；超出窗口高度时可滚动查看当前三段。完整内容仍按记录规则写入 TXT；调整字号会同步调整窗口所需高度，跟随模式仍受屏幕可用空间限制。待译句按原顺序进入最多 12 个任务的队列；单句错误或空结果最多重试两次，超时预算包含串行排队等待，最终失败会显示计数。

程序通过 UI Automation 读取字幕，不接管 Windows 的音频或识别引擎，不修改识别结果；只有用户操作麦克风或方向按钮时才通过原版菜单切换对应设置。原版字幕不存在时会尝试启动它。Edge 模型仍会消耗 CPU、GPU 或内存，是否引起目标电脑识别延迟需要实机测量，不能保证完全没有性能影响。

点击设置打开独立窗口，调整字体、窗口高度、译文颜色、透明度和翻译方向，或执行暂停、复制、清空、打开记录文件夹、恢复 Edge 和诊断。高度滑杆支持 160–1200，立即生效保存；跟随模式受屏幕空间限制。右下角握柄放大为 28×28，连续拖动按屏幕位移计算，不受窗口跟随移动干扰。采集优先读取 UIA 可见文字范围，不支持时保留原读取回退；需在目标 Windows 版本实测旧句滚出行为。译文默认黑色，可通过色块切换黑、白、绿、蓝、红，立即生效并随个人设置保存；背景透明度不影响文字颜色或不透明度。关闭设置窗不会退出字幕程序；主窗口的退出键才会完整退出。“验证模型”使用固定样句调用真实 Edge，**不等于验证了音频链路**。

字幕语言对缺少模型时，在 Edge 页面点击“下载所选字幕模型”，不会因更改方向而自动下载。中英字幕复用默认双向模型，其他方向最多保留一个额外字幕模型，切换或退出时释放；手动翻译仍最多保留一个额外模型。任务、结果校验和会议 TXT 均保存实际源／目标语言。

网页首次打开时采用悬浮窗当前方向，之后两端互不联动；重连也不覆盖网页选择。网页和悬浮窗设置均有交换方向的箭头按钮，一键交换各自的源／目标语言，悬浮窗交换立即应用并保存。更换字幕源语言后仍需手动匹配 Windows 识别语言，无需确认勾选；外面的中英识别快捷按钮保留。

运行期间默认自动逐段写入 `%LOCALAPPDATA%\LCET\transcripts`，每次运行一个 UTF-8 TXT，包含时间、句段编号/版本、原文及译文。完整译文在分段标点（包括逗号）后稳定约 1 秒记录；无标点的末句等待约 2 秒停顿。预览不入档，相同版本只记一次，后续识别修订追加带版本号的记录。清空窗口不删除文件。正常退出先结束后台写盘，再询问是否保留本次记录；保留后用系统默认应用打开，不保留则删除本次文件。没有记录时不弹空提示，强制结束进程无法保证弹出确认。后台处理最多 80 个片段，待写盘队列最多 128 条；以前的文件不自动轮换或清理，请按会议保密要求管理。

字幕与手动翻译自动记录，不提供隐私模式开关，也不以该模式限制复制。旧设置中的隐私字段会被忽略，之后保存设置时移除；无需删除个人设置或会议文件。会议 TXT 包含明文原文和译文，请按组织保密要求管理。

## 环境

用户端：Windows 11 x64、Windows PowerShell 5.1、.NET Framework 4.8.1 Runtime、Edge 148+，以及对应 Windows 识别资源和 Edge 中英双向模型。企业策略必须允许脚本、DLL、本机监听和 Translator API。

开发端另需 Visual Studio Build Tools 的 .NET 桌面生成工具与 .NET Framework 4.8.1 development tools。没有 NuGet、npm 或第三方运行库依赖；Node.js 仅用于开发时的浏览器调度测试。

```powershell
powershell.exe -NoProfile -File .\build.ps1 -Test
```

默认构建输出为 [bin/LCET.dll](bin/LCET.dll)，原 BAT 启动器在 STA PowerShell 中加载它。用户电脑无需编译。另可只构建 x64 图形 EXE，不启动程序：

```powershell
powershell.exe -NoProfile -File .\build.ps1 -Exe
```

EXE 输出为 [bin/RTTL.exe](bin/RTTL.exe)，发布入口为 [RTTL/RTTL.exe](RTTL/RTTL.exe)。它直接以 STA 运行现有应用，不依赖 PowerShell 宿主，仍需 .NET Framework 4.8.1、Edge 和随包网页配置，不是单文件打包。EXE 构建不能与 `-Test` 同时使用；本次按要求仅编译及静态检查，未运行。构建前应先正常退出使用对应输出文件的运行实例，避免文件被占用。
