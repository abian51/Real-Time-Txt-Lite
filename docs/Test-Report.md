## 已知限制与取舍

- Windows 识别语言采用用户确认，不声称已自动识别/切换；方向变更清空现有字幕，防止错误语言结果覆盖。
- 字幕算法是有界快照重叠和末句修订启发式；复杂跨多个已提交句子的追溯改写、滚动与整句重写同时发生时仍可能重新分段，必须以真实语料完善。
- 最长约 220 字符切分；缩写、数字句点等复杂分句仍可能影响质量。目前不额外拼接历史句到翻译输入，避免重复译文；上下文质量需要语料评估。
- UIA 使用 250 ms 轮询，未宣称属性事件更可靠。重新定位限定每 2 秒，缓存控件；未知 Windows 控件布局仅提示不支持，不回退 OCR。
- 隐私模式已移除，总处理上限为 80 条。界面最多三条纯译文。两端待翻译任务最多 12 个，待写盘最多 128 条；超过处理上限、持续磁盘故障或翻译失败不保证完整会议记录。自动记录会保存含原文/译文的明文 TXT，文件需另行管理保留期。
- 暂不隐藏原版字幕窗口，避免未验证隐藏后 UIA 可读性；未提供托盘或 SRT 导出，均不阻塞 MVP。
- 未进行正式桌面截图/移动布局自动化验收；原生界面与浏览器诊断页仍需人工观察不同 DPI、分辨率、长文本布局。
- 正常退出有释放信号；异常杀死宿主不能保证浏览器立即释放。旧页 SSE 重试有上限，且不会生成翻译任务。应用不结束整个 Edge 进程。
- 不自动断开用户网络、改变 Windows 识别语言或启动会议音频来取得测试结果。后续人工验收应使用已获许可的非敏感测试音频。
