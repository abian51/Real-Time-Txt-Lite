# 部署与故障排查

## 用户端准备

1. Windows 11 x64 的当前交互式桌面会话，不以服务、锁屏采集或管理员身份运行。
2. 系统内置 .NET Framework 4.8.1 与 Windows PowerShell 5.1。
3. Edge 148+，企业策略允许设备内 Translator API 和模型下载。
4. Windows 实时字幕安装相应中英文语音资源；首次授权和模型下载由用户完成。
5. IT 允许此目录下的 BAT、PowerShell 脚本和 DLL，并允许普通用户绑定回环端口。应用不修改执行策略、Defender、EDR、AppLocker 或 WDAC。

复制运行所需文件：[start.bat](../start.bat)、整个 launcher、bin、web、config 目录。源码、测试和开发工具不必交付用户。保留文件的相对位置；支持中文与空格目录，不依赖当前工作目录。已下载浏览器模型属于 Edge 管理资源，不随项目目录复制给其他电脑。

若下载文件带有组织的安全标记或策略限制，应由 IT 审批授权；不建议批量解除标记或绕过策略。被策略阻止时，启动控制台保留错误提示。

## 首次运行与日常操作

双击启动入口后：环境检查 → WPF 窗口 → 自动查找/开启实时字幕 → 启动回环服务 → 打开 Edge 页面 → 检查并复用双向模型。

无边框主窗口显示最多三段译文，每段另起一行，长段按窗口宽度自动折行，不显示原文或历史列表，文字控件固定复用，显示缓存最多三条。中英文逗号也作为分段点，但保留 `1,000` 等数字中的逗号。下一段待译、识别修订或可见范围短暂为空时保留上一屏，当前范围有译文后才移除不再符合范围的旧段并更新；迟到历史结果继续按记录规则写入 TXT，不补播到窗口。当前未完句原文的完整前缀滚出可见范围时，匹配的尾部仍有显示资格，仅限当前段，历史段不放宽。显式清空、方向切换和会话重置仍清除显示；首次没有译文时仍显示等待，本改动不改变模型性能或重试策略。长译文不再省略，超出窗口高度时可滚动查看当前内容，完整内容仍按记录规则写入 TXT。右上角包含麦克风、方向、设置与退出按钮；字体、透明度和其他操作位于设置窗。关闭设置窗只收起设置，主窗口退出键才会完整退出。

默认开启“跟随 Windows 字幕”。程序复用 UIA 采集器已经绑定的窗口句柄，每约 100 ms 检查位置，通过本机窗口坐标对齐左边和宽度，不额外高频扫描 UIA 树。优先贴在下方；空间不足时放到上方，两边都不足时缩短翻译区高度，不覆盖原版字幕。使用目标显示器工作区避免任务栏；完全没有邻接空间时回到独立窗口。

跟随模式下原版字幕控制位置和宽度，翻译窗不能单独拖走，右下角握柄只调高度。握柄为 28×28，按拖动起点的屏幕总位移计算尺寸，避免跟随移动干扰连续拖动；设置另有“窗口高度”滑杆，范围 160–1200，即时应用并保存，跟随时实际高度仍受屏幕空间限制。关闭开关后恢复原独立窗口位置与尺寸，可拖动字幕区/空白区移动、握柄自由调宽高。保存时记录独立窗口尺寸，不把临时同步的宽度覆盖为用户默认。关闭/隐藏字幕窗口时退回独立显示；窗口重新可用后自动继续绑定。应用不会为贴靠修改 Windows 字幕本身的样式、位置或大小。

默认直接英语→中文，首次无需手动确认；启动不自动检测或切换 Windows 语言，请先在原版字幕中选择 English (United States)。外面的中英方向按钮仍通过 UI Automation 同步切换美式英语／简体中文识别及双向翻译，成功后重设完整语言对。设置窗的独立源／目标选择器使用共用语言目录中的 154 个候选项，选中即应用保存，移除应用按钮及确认勾选；选到另一端语言时自动交换，程序化更新受重入保护。更换源语言后需手动匹配原版字幕语言，不以确认字段阻塞处理，旧 LanguageConfirmed=false 也不阻塞。其他候选语言不保证 Windows 识别或 Edge 翻译可用。切换取消旧任务，迟到旧结果被拒绝，TXT 保留实际语言对。麦克风按钮仍控制 Windows 字幕识别而非系统静音，锁屏和原版窗口未连接时禁用原生控制。

字幕采集优先读取 TextPattern.GetVisibleRanges()，避免完整无障碍 Name 包含滚出历史而保留旧译文；可见范围为空时提交空快照清除显示。不支持 TextPattern 或可见范围时保留 Name／DocumentRange／ValuePattern 回退。不同 Windows 提供程序的真实行为仍须实机验证。

默认使用正常 Edge 新窗口，而非 WebView2、headless 或专用用户配置。会复用用户现有的标准 Edge 模型。模型就绪但后台休眠导致心跳超时，会显示原因并有限重开状态页（最多 3 次）；浏览器 SSE 连续失败 6 次停止自动重连。手动“恢复 Edge”可再次尝试。休眠页原窗口可能仍然保留，不强杀浏览器进程。

网页手动翻译提供独立源／目标选择器，默认英文→中文；与悬浮设置共用 [web/languages.json](../web/languages.json)，154 项中英文、简体中文、日文置顶。字幕方向通过原生 control 事件传给网页，最多保留一个额外字幕模型；手动翻译方向独立，另最多保留一个额外手动模型。两者复用默认中英模型，不支持的字幕语言对显示原因，缺少字幕模型时由用户点击“下载所选字幕模型”，切换设置不会自动下载。新增语言目录属于运行文件，分发时不可遗漏。

网页手动方向只在首次有效 control 事件时采用原生源／目标，之后不随字幕变化；用户首次握手前已经选择语言时保留其选择。重连不重新初始化，刷新或重新打开页面才重新采用当前原生方向。网页交换按钮只更改手动方向，翻译、模型准备或写盘确认期间禁用；悬浮设置交换按钮原子地应用并保存，无需确认勾选，保留中英快捷按钮。

网页已取消 Windows 语音包自动查询及安装状态判断，改为固定提醒和微软官方安装说明链接。实时字幕只需在其“字幕语言”菜单中为所用识别语言选择下载语音包，不要求完整 Windows 显示语言包，也不必为翻译目标安装语音包；Edge 模型单独下载，纯文本翻译无需 Windows 语音包。没有已验证的语音包直接下载深链接，因此入口打开官方操作说明，而不是承诺自动安装。

“暂停”会停止字幕正文读取与翻译排队，取消浏览器待处理及进行中的字幕任务；窗口存在性检查、重新绑定和位置跟随仍继续。Windows 自己的语音识别仍可能继续运行；继续时只处理仍然可见的字幕，暂停期间不可见的内容无法追溯。

“清空”不会改变 Windows 原版字幕内容；当前相同快照不会立即重新出现，有新变化时按新快照恢复。

默认自动保存稳定的完整译文，每次运行一个 UTF-8 TXT，位于 `%LOCALAPPDATA%\LCET\transcripts`；设置中的“记录文件夹”可以直接打开。记录包含时间、句段编号、版本、方向、原文和译文。同一版本不重复写，识别修订追加新版本。分段标点（包括逗号）后稳定约 1 秒或无标点末句停顿约 2 秒后才入档，正常退出会提交已有完整译文并等待写盘。

有本次记录时，正常退出会询问“是否保留本次会议记录”：选择“是”保留并用系统默认应用打开 TXT，选择“否”删除本次文件，不删除以前的会议记录。没有记录时不提示。删除前确认后台写入线程已停止，防止文件被迟到写入重建；保存、删除或打开失败会显示本次文件路径。强制杀死宿主或直接结束控制台无法保证弹出确认，已落盘文件可能保留。

处理片段最多 80 个，翻译任务最多 12 个，独立后台写盘队列最多 128 条，不把全文长期留在前端或内存。待译句按原顺序提交，不先截取最新 12 句；单句错误、空结果和超时最多重试两次，原生超时预算包含浏览器串行队列的等待时间，重试耗尽会显示失败计数。以前的文件不自动删除或轮换，需按组织会议保密、磁盘空间与保留期要求管理。磁盘异常会在状态栏显示 TXT 错误并重试；持续磁盘故障、翻译失败或超过处理上限的积压仍可能缺句，不能保证完整会议记录。退出先等待写盘最多 5 秒，超时记录 `flush_timeout`，收尾时再等待线程停止最多 1.5 秒；仍未停止则不删除文件并报错，未落盘内容可能丢失。

不再提供隐私模式，字幕与手动翻译自动记录，复制不受该模式限制。旧配置的隐私字段会被忽略，再次保存设置时移除。锁屏时仍停止字幕处理并拒绝手动记录。处理上限为 80 条，清空显示不删除已有记录文件。

## 设置与诊断

默认配置来自 [config/defaults.json](../config/defaults.json)。运行后的设置存储于 `%LOCALAPPDATA%\LCET\settings.json`，技术日志在 `%LOCALAPPDATA%\LCET\logs\technical.log`。

- `SourceLanguage` / `TargetLanguage`：独立源／目标代码，默认 `en` / `zh`；必须为共用目录中的不同语言。旧配置没有目标字段时保留原来的中英反向目标。
- `LanguageConfirmed`：为兼容旧配置保留；原生启动与方向应用设为 `true`，不再参与处理或暂停判断，也不代表已自动检测 Windows 识别语言。
- `LanguageSetupVersion`：保留旧配置加载迁移版本 1；新的原生界面不再使用确认勾选或确认门槛。
- `PollMs`：200–1000，默认 250 ms。正常轮询只读已绑定控件；重新定位最多每 2 秒一次。
- `DebounceMs`：300–1000，默认 400 ms。
- `FontSize`：14–40；`Opacity`：0–1，仅控制背景不透明度，默认 0.5，字幕和按钮不随背景变淡。设置窗保持不透明。背景完全透明时，可拖动文字移动窗口。
- 窗口默认高度 160，最小独立尺寸 420×160；高度滑杆为 160–1200。独立窗口握柄调整宽高，跟随时仅调高度，尺寸与位置保存。
- `OverlayLayoutVersion`：布局迁移版本。版本 1 将最初旧版透明度重设为 0.5；版本 2 将旧默认高度 300 改为 240，并将已保存的不透明度用于背景。用户自定的其他高度保持不变。
- `FollowWindowsCaptions`：默认 `true`；可在设置中关闭并恢复自由窗口。

修改 JSON 前先退出应用；损坏的设置会回到默认设置，仍然自动记录。窗口位置会限制在当前虚拟屏幕范围。技术日志上限约 256 KB，保留一个轮换文件，仅记录模块、状态/错误类型与耗时，不记录字幕、译文、会话 Cookie；字幕正文只进入独立的 transcripts 目录。删除整个用户目录还会删除会议 TXT，重置设置时应先保留所需记录；不会卸载微软语言资源。

诊断里的“文本变更到结果”耗时包含防抖和通信，**不是**文档定义的“稳定字幕到显示”，也不是 Windows 音频到识别时间。引擎耗时在日志中按 `en_api` / `zh_api` 区分，正式性能报告需另外采样。

## 常见问题

| 现象 | 处理 |
|---|---|
| PowerShell 显示脚本禁止执行 | 联系 IT 授权启动脚本；不要使用 Bypass 或关闭防护 |
| 缺少 DLL/网页 | 完整复制目录；开发机先构建，用户机无需 SDK |
| UIA 等待语音 | 正常空闲状态；播放音频并确认 Windows 当前语言 |
| 找到窗口但控件不支持 | 完成 Windows 首次授权/语言资源设置；仍失败时提供 Windows 版本与 UIA 状态，不能用 OCR 静默替代 |
| UIA 失效 | 每 2 秒尝试重新定位；重开 Windows 字幕后自动绑定 |
| API 不可用 | 核对 Edge 148+ 与企业策略，不回退云服务 |
| 模型需下载 | 每次打开页面先检查；缺少模型时提示“点击下载微软翻译模型”，下载期间显示“下载中...”，双向已下载或下载完成后显示“已安装”。已有下载进行中时会自动复查完成状态，不重复发起下载。授权/下载可能需要联网；已安装时点击同一按钮可做双向固定样句连通测试，下载完成不自动测试 |
| API NotAllowedError | 在 Edge 页手动点击准备按钮，满足浏览器交互要求 |
| 模型验证未执行 | 先准备双向模型，暂停字幕翻译后重试 |
| 字幕不翻译 | 检查语言确认、暂停、UIA 和模型状态，而非只看浏览器进程是否存在 |
| Windows 识别或显示延迟 | 程序只读 UIA，不接管音频、不修改识别结果；Edge 模型可能争用 CPU/GPU/内存，需要对照退出程序前后资源和识别表现。迟到旧译文只归档，不补播；当前句未返回时可以暂时没有译文 |
| Edge 心跳超时 | 恢复窗口或点击恢复 Edge；组织休眠策略需由用户/IT 使用官方设置处理 |
| 控制台关闭或进程被杀 | 无法保证发送浏览器释放消息；页面检测到本机服务断开后有限重试并停止，需要手动关闭残留项目页 |
| 退出后仍有 Edge 进程 | 属于共享浏览器或后台模型进程，不会强杀；项目会话正常退出时调用 destroy |

正常退出只尝试关闭应用自行启动且仍能确认归属的 Windows 字幕窗口；原有字幕不关闭。对于无法确认归属的窗口，宁可保留，不关闭用户资源。网页收到退出事件后释放会话并尝试 `window.close()`；浏览器若拒绝关闭，状态页可能保留，但任务已停止。

## IT 安全边界

HTTP 使用 IPv4 `127.0.0.1` 的操作系统分配端口，无 HttpListener URL ACL、不需要管理员或防火墙入站规则。拒绝不匹配的 Host/Origin、跨站 Fetch Metadata、无会话 Cookie 的接口访问。会话 Cookie 随机生成、HttpOnly、SameSite=Strict，不出现在查询串和日志；网页和接口同源，不启用 CORS。

这是防止其他网页滥用的基本保护，不是针对同一 Windows 用户下恶意本机程序的安全隔离。因为服务是回环 HTTP，Cookie 不标记 Secure。页面 CSP 限制脚本和连接到同源，不嵌入远程代码；Edge 模型下载和浏览器自身联网行为不由 CSP 禁止。
